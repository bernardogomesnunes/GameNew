## PLAY-14: mushrooms

### Where the first ones come from

Wild mushrooms are scattered on forest floors through `BIOMES[].scatter` (`biomes.js`). Each is one entry; `ChunkGen.scatterAt` costs one hash per entry per column, no extra pass. Entries go after any existing ones, so hemp keeps its index `n` and its positions.

| Biome | Ground | Entries appended |
|---|---|---|
| Oak Forest (`forestOak`) | `MOSS` | `{ block: 565, chance: 0.003, on: MOSS }`, `{ block: 567, chance: 0.003, on: MOSS }` |
| Birch Forest (`forestBirch`) | `GRASS` | `{ block: 567, chance: 0.003, on: GRASS }` after the hemp entry |
| Dark Forest (`forestDark`) | `DARK_MOSS` | `{ block: 566, chance: 0.004, on: DARK_MOSS }`, `{ block: 565, chance: 0.002, on: DARK_MOSS }` |

A forest chunk has 256 columns and trees take some, so this is about 1 mushroom of each listed kind per chunk.

Only changed chunks are saved (`World.js:111`); unchanged ones regenerate from the seed. Old worlds therefore get mushrooms in every forest chunk nobody has edited. Edited chunks keep what they have.

Nobody sells mushrooms. The wild scatter and the log are the two ways (PLAY-11 asks for few ways per item).

## PLAY-15: the Mushy Log

### Decisions

- Three logs, one per kind. The recipe takes 2 of that kind's mushroom as the seed. One log with a mixed harvest was the other choice; it gives no control over which caps you get.
- 10 game days to ready, the sapling clock (`DuiltGame.days`, which runs only while you play and jumps when you sleep).
- Yield 15 to 25, mean 20, fixed by place and day (below).
- Single use. Breaking a ready log gives the mushrooms and the log is spent. The owner's numbers are per log; a reusable log would multiply them and needs a flush count in its state. This is open question 1.
- Breaking it before it is ready gives the Mushy Log item back. The 10 days start again when it is placed again.

### Code: `src/duilt/MushyLogs.js` (new)

Modelled on `src/duilt/Saplings.js`.

```js
export const MUSHY_KINDS = {
  red:   { base: 556, item: 'mushroom_red',   log: 'mushy_log_red' },
  lilac: { base: 559, item: 'mushroom_lilac', log: 'mushy_log_lilac' },
  pale:  { base: 562, item: 'mushroom_pale',  log: 'mushy_log_pale' },
};
export const MUSHY_GROW_DAYS = 10;
export const MUSHY_STAGE_DAYS = [0, 4, 10];   // a stage starts on these days
export const MUSHY_MIN = 15, MUSHY_MAX = 25;

/** { kind, stage } for a mushy log block, or null. */
export function mushyOf(blockId) { ... }

/** The yield of the log placed at (x, y, z) on game day `at`, in a world of `seed`. */
export function mushyYield(x, y, z, at, seed) {
  const salt = (seed ^ 0x6d75 ^ Math.imul(y | 0, 0x9e3779b1) ^ Math.floor(at * 1000)) | 0;
  const s = hash01(x, z, salt) + hash01(x, z, salt ^ 0x5bd1);   // 0 to 2
  return MUSHY_MIN + Math.round(5 * s);                          // 15 to 25, mean 20
}

export class MushyLogs {
  planted;                          // Map "x,y,z" -> { x, y, z, at, kind }
  plant(x, y, z, at, kind) {}
  take(x, y, z) {}                  // removes and returns the record, or null
  get(x, y, z) {}
  stageOn(rec, today) {}            // 0, 1 or 2 from MUSHY_STAGE_DAYS
  daysLeft(x, y, z, today) {}       // whole days to ready, 0 once ready
  grow(world, today) {}             // returns changes [{ x, y, z, prev, next }]
  toJSON() {}                       // [{ x, y, z, at, kind }]
  loadJSON(list) {}                 // drops entries without finite x, at or a known kind
}
```

- `hash01` is `world/ChunkGen.js:141`. The sum of two uniform draws gives a triangle peaked at 20: 15 and 25 each come up 0.5% of the time, 20 about 19%.
- `at` is the fractional game day the log went in, so the same spot placed again on another day rolls again. Reloading a save does not reroll.
- `grow` skips unloaded chunks. It drops a record whose block is no longer one of its kind's three ids. It sets the block to `base + stageOn(rec, today)` when that differs from what stands there.
- The seed is `world.gen?.seed ?? 0`, as `Saplings.treeFor` reads it.
